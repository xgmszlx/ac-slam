## 0. 结论与建议（**暂停点，40/48 条**）

本轮于 2026-10-10 下午按用户要求暂停：48 条主实验中 **40 条成功、1 条技术失败待重试、
1 条被打断、6 条未跑**，有限重复性检查尚未执行。以下判断是暂停点的阶段性结论，最终
数值与"是否超出重跑噪声"的判决需在补完剩余 8 条与重复性检查后复核。

阶段性结论（数值见第 6 节）：

1. **返回段确实在补充约束**：return 阶段的信息增益在三个动作臂上都是正的
   （S1 +0.082、L+ +0.121、L− +0.088 nats 均值，S0 臂 +0.056），说明"返回"这一步本身
   就带来了可观的目标约束，与 Q1 的担心一致。
2. **额外旋转仍能补充信息，但不是"大幅旋转占优"**：动作阶段增益均值 S1 +0.097、
   L− +0.120、L+ +0.069、S0 恒为 0.000（10/10 全零）。小的 S1 动作与大幅 L− 相当，
   而 L+ 反而是三个运动臂中最弱的，且在 4/10 条里恰好为 0。
3. **方向有系统性差异**：配对组内 `L+−L−` 均值 **−0.051**（9 组中仅 3 组为正）、
   `L+−S1` 均值 **−0.035**（3/9 为正）；反方向 L− 在 10/10 条都为正增益，说明"相同
   累计转角、相反方向"在多数地点不等价。
4. **S1 并非主要受关键帧门限限制**：动作阶段实际关键帧数 S0 0.0、S1 1.2、L+ 5.9、
   L− 5.7；S1 在多数 episode 中不触发新的关键帧，却仍取得与 L± 同量级的信息增益。
5. **图信息增益没有对应可测的真实误差变化**：目标状态的真实位置误差在动作前后变化
   ≈ +0.0001 m（40 条均值），与 `action_gain` 的相关系数仅 +0.18（return 为 −0.06）。
   在 48 条全部完成前不宜把它解释为"信息提升了定位精度"。
6. 最优先的下一步（暂停点建议）：**先补完剩余 8 条与重复性检查**，再用"同条件重跑
   散布"判断上述 L+−L− / L+−S1 差异是否超出噪声；若差异 ≤ 重跑散布，则应把结论收缩
   为"额外旋转收益与返回段同量级、方向差异不可用于选择"。

## 1. 本轮问题与判据

* **Q1**：完整保留首次经过、离开、返回和局部动作后，额外旋转到底还能增加多少信息？
  返回途中是否已经获得主要收益？
* **Q2**：相同预算下，大幅旋转是否仍基本占优？相同累计转角、相反旋转方向，是否会因
  为场景及历史观测方向不同而产生稳定差异？
* **Q3**：差异是否足够大、足够可解释，值得继续做方法研究？

判据（冻结于 `experiment_plan.json`，不在看到结果后修改）：

1. 同一次连续运行内四阶段（history / return / action / tail）的图快照；
2. 目标身份在动作前冻结（不读动作结果）；
3. 相同采样预算（动作阶段 347 条有效扫描）；
4. 组内顺序轮换，抵消顺序效应；
5. 无增益或负增益同样作为有效结果保留。

**判读规则（在看到主实验结果之前写入，避免事后挑选）**：

* 尺度基准：主实验完成后，`repeatability/` 给出四个固定配置各 3 次执行（1 次主实验 +
  2 次重执行）的 `action_gain` 组内标准差 `s_rep`，作为“同条件重跑差异”的尺度。
* Q1：比较同一 episode 内 `action_gain` 与 `return_gain`。若 `action_gain` 的中位数
  在四个动作上都 ≤ `s_rep`，则判为“返回段已基本完成约束补充，额外旋转不增加可用信息”；
  若 L± 的 `action_gain` 中位数 > `s_rep` 而 S0/S1 不满足，则判为“只有大转角能补充”。
* Q2：比较组内配对的 `L+−L−` 与 `L+−S1`。若 |配对差| 的中位数 ≤ `s_rep`，判为“方向/
  强度差异不超出重跑噪声”；若 > `s_rep` 且方向一致（同一地点多数重复同号），判为存在
  可利用的稳定差异。
* Q3：只有当事前可用信息（关键帧触发数、观测朝向新覆盖率、目标段几何）与动作排序差异
  有单调关系，且该差异超过 `s_rep` 时，才建议继续做方法研究；否则建议收缩该路线。
* 所有结论同时报告逐地点数值，不用单一均值掩盖地点间差异。

## 2. 冻结的设计

### 2.1 地图与路线

地图 `map3`（74 m × 74 m，24 根 3.9 m × 3.9 m 柱子，12 m 网格，外围墙）。机器人起点
`(-28.0, -28.0, 0)`。路线为一个 64.4 m 闭环，四个地点取在闭环四角：

| 地点 | 世界坐标 | 最近障碍 | 6 m 内障碍点 | 被占 30° 扇区 |
| --- | --- | --- | --- | --- |
| A | (-30.50, -18.00) | 4.60 m | 860 | 7/12 |
| B | (-5.95, -18.00) | 6.94 m | 0 | 0/12 |
| C | (-5.95, -30.00) | 5.10 m | 466 | 6/12 |
| D | (-30.50, -30.00) | 4.60 m | 1226 | 9/12 |

路线最差净空 1.10 m；四个地点的最近障碍距离与遮挡结构互不相同（这是选点的唯一依
据，使用 `scipy.ndimage.distance_transform_edt` 在静态楼层图上测量，不含任何动作结
果）。五段航点（相对起点坐标）：

```
A  (-2.50, 10.00,   0.0)      C  (22.05, -2.00,  pi)
B  (22.05, 10.00, -pi/2)      D  (-2.50, -2.00,   0.0)
FINISH (6.00, -2.00, 0.0)
```

机器人在 history 段依次经过 A→B→C→D→FINISH；place_X 的“历史观测”发生在机器人
第一次到达该航点时（航点朝向即观测朝向）。return 段从 FINISH 直接回到该地点。

### 2.2 四个动作（冻结剂量）

| 动作 | 命令模板 | 计划累计转角 | 含义 |
| --- | --- | --- | --- |
| S0 | 保持 | 0 | 额外的静止观测基线 |
| S1 | `θ0 → θ0 + 1.087946562824985/2 → θ0` | 1.087946562824985 rad | 小动作，接近旧关键帧阈值 0.52 rad |
| L+ | `θ0 → θ0 + π/2 → θ0` | π rad | 正向大动作 |
| L− | `θ0 → θ0 − π/2 → θ0` | π rad | 相同开销的反向大动作 |

动作阶段固定保留 **347 条有效扫描**（历史预算），动作结束后原地静止补足。

### 2.3 矩阵

4 地点 × 3 次重复 × 4 动作 = **48 条**，组内动作顺序按 `rotate(['S0','S1','L+','L-'],
group % 4)` 轮换。每条记录 `tsp_seed = 44000 + sequence`，串行执行。

## 3. 连续采集链路与快照边界保证

每个 episode 是一次独立的 Stage + Karto 运行（交接文档 §4.1 方案 b），不做任何后缀
拼接、不复用旧拼接模块：

```
初始建图 → history 航点 A..FINISH → G_before_return → 返回航点(历史观测位姿)
→ G_arrival → 动作阶段(347 帧) → G_action_done → 静态尾段 → G_final
```

驱动 `driver.py` 只观测，不写入 mapper 的任何输入：

* 逐条记录原始 `/base_scan`（float32 线级距离）、该扫描时刻在**无修正里程计链**
  `odom → base_laser_link` / `odom → base_link` 中的位姿（TF 查询失败时记录实际使用
  的位姿年龄）、以及 SLAM 修正后的 `map → base_link` 位姿；
* 记录 `/base_pose_ground_truth`、`/others`（被接受的关键帧位姿，用于状态—时间对
  应）、`/Mapper/loop_closed` 与 `/Mapper/closure_edges`；
* 四个边界快照包含完整位姿图（节点、边、协方差上三角）、`/slam_path`、扫描序号与
  边界记录。

**边界保证（写入每个快照，不假设）**：mapper 没有逐扫描处理确认，因此快照在“该阶段
最后一条扫描之后、且至少 0.5 s 内没有新的完整图消息、没有新的被接受关键帧事件”时
才取；分析阶段另行核对各阶段的节点/边计数与扫描序号，并写入
`analysis/per_episode_metrics.csv`。

## 4. 指标定义

* **J_T**：五个冻结目标状态的 `-logdet(marginal)/15`（15 自由度），锚定在最小状态
  id 上；实现与上一轮 `tools/realizability_pilot/action_selection_exploratory.py`
  完全一致（`cho_solve` 同一路径），因此与旧轮次数值可比。
* **阶段增益**：`return_gain = J_T(G_arrival) − J_T(G_before_return)`、
  `action_gain = J_T(G_action_done) − J_T(G_arrival)`、
  `tail_gain = J_T(G_final) − J_T(G_action_done)`。
* **测量灵敏度检查**：对每条 episode 的最终图追加一条连接两个目标状态的合成边，重算
  J_T；若该响应非零，则“测得为零”是真实零而不是指标失灵（结果在
  `analysis/summary.json:measurement_sensitivity`）。
* **真实误差变化**：把目标状态的图位姿用**每次 episode 只拟合一次**的刚体
  `map→GT` 变换（只用动作前存在的状态拟合）对齐到真实位姿，报告五个目标状态的平均
  位置/朝向误差在四个边界上的变化。
* **观测朝向**：动作阶段把机器人朝向写成 `θ0 + (odom yaw − odom yaw@动作开始)`（无修
  正里程计），历史集合取冻结目标状态自身的朝向；`new_heading_fraction` 为动作阶段中
  与所有历史朝向相差 ≥15° 的扫描比例。
* **关键帧门限**：动作阶段实际产生的关键帧数（`/others` 事件），用于判断 S1 是否受
  0.52 rad 关键帧门限限制（交接文档 §4.2 要求）。
* **代价**：动作阶段实际累计转角与时长（来自无修正里程计与扫描时间戳）。
* **约束来源**：按边序号增量统计 return / action / tail 三个阶段新增的连接边，并区分
  顺序边（里程计）与非顺序边（回路闭合），同时给出与目标状态直接相连的新边。

## 7. 对三个问题的回答（**暂停点，待剩余 8 条与重复性检查复核**）

**Q1（返回段是否已经获得主要收益）**：不是"主要收益全部来自返回"，但两者同量级。
返回段均值 +0.056…+0.121 nats，动作段 +0.000（S0）/+0.097（S1）/+0.069（L+）/+0.120
（L−）。也就是说，在已经完整保留"经过—离开—返回"之后，额外旋转仍能再补一份与返回
段相当的信息；但没有任何一个动作臂达到"返回段的数倍"。

**Q2（大幅旋转是否仍占优；方向是否有差异）**：暂停点数据显示**不占优**。小的 S1 动作
与反方向 L− 的均值都超过正向 L+；配对比较 L+−L− 均值 −0.051 nats（仅 3/9 组为正），
L+−S1 均值 −0.035（3/9）。方向差异与地点相关（place_B、place_C 上差异最大），提示
"相同累计转角、相反方向"改变的是被观测几何的覆盖，而不是单纯的剂量。

**Q3（是否值得继续方法研究）**：暂停点尚不能支持。需要先用重复性检查给出同条件重跑
散布 `s_rep`，再判断 |L+−L−|≈0.05 nats 是否超出噪声。若超出且与事前可用特征（关键帧
数、观测朝向覆盖、目标段几何）单调相关，则值得做选择器研究；否则应把结论收缩为
"额外旋转与返回段同量级、方向差异不足以支撑选择"。

## 9. 限制、偏离与下一步

* 有限重复性检查以**重新执行相同配置**实现（每配置 +2 次，共 8 次后端运行，仍在交接
  文档的 12 次预算内），而不是离线重放录制输入：本轮链路按交接文档 §4.1 方案 b 为原生
  连续采集，设计上没有录制 mapper 输入流，为其新建重放发布器等于新增一条受测后端路径。
* 动作的实际峰值偏转比命令值大约 0.3 rad（导航器原地回转超调），四个动作同向同量，
  已逐条记录实际值；这不改变动作之间的相对剂量。
* 单地点、单地图、单后端（Stage + Karto）。所有结论仅适用于该条件。
