# NGD-M0-compat bounded recovery

Fixed NGD author commit a93a14c4019efc7a209be5fbf9fefa46f5d1d90f. Parent archive81fe14af7aad477eba773d4d0b61ba971511a3c7 remains untouched. Existing isolated OpenCV4.5.5, vocabulary and verified model are reused from KESU. No system library installation or download.

1. `register.py` captures old source/binary/Git hashes, copies old binaries and freezes primitive cases, five real image indices and short/full gates. It is one-time and refuses overwriting the registration.
2. Build `ccl_probe.cc` with `/usr/bin/g++ -std=c++14 -O2 -g`, private OpenCV include/lib/RPATH and `-lopencv_imgproc -lopencv_core`. `test_ccl.py` runs24 independent subprocesses, caps time and disables cores; it stores negative signal returncodes. Probe labels are compared after canonicalization against an independent four-neighbor BFS. Largest region and the inherited dilation/80%clear output are saved outside the repository. Failed cases also have saved GDB stacks (`ccl_gdb.log` is the initial first-case investigation; `stack_*.log` cover all four failures).
3. `build_compat.py` copies the428 verified author files to the new KESU source tree, modifies one YOLO expression only, compiles YOLO.cc with the existing native flags, and links with all other original object files. Old libraries are never overwritten. The original headless example object is reused unchanged. Commands and loaded library paths are in `compat_build.json`.
4. `yolo_mask_probe.cc` calls unmodified author public Detect. Link original and compatible versions in separate processes, using recorded native-example compile/link arguments. `test_real_masks.py` compares five fixed existing inputs at indices0/206/413/620/826 and uses private OpenCV, original model and threads1. It evaluates final binary detection masks, not online propagated masks or SLAM influence.
5. `run_stage.py short` is the only normal short-SLAM call. It uses12 original consecutive associated inputs. The script refuses an existing stage directory, writes `results/<stage>/frozen.json` before launch, captures actual process maps and moves new trajectory outputs to that stage only if present. `run_stage.py full` requires successful12-frame exit0 before starting and therefore was NOT invoked. No old registration paths were reused.
6. One GDB run of the same short command after the short failure captured the main-thread CreateMaskFromClusters fault. Environment includes `OPENCV_FOR_THREADS_NUM=1`, the compatible NGD library path and existing private OpenCV/dependency paths. Command is recoverable from short/frozen.json; replace its time wrapper with `gdb -nx -batch -ex run -ex 'thread apply all bt 12' --args <program and args>`. This is a diagnostic prefix, not a full sequence or another method trial.
7. `finalize.py` verifies old source/binaries/worktree protection, one changed author file, valid mask comparisons and failed-short status. The existing evaluator is copied without numerical changes but was not executed, because no full trajectory exists.

Local derived binary label arrays and masks remain under the external `probe_outputs`; publication keeps only tables/logs/patch/commands and hashes. It excludes original images/GT, models, vocabulary, archives, all executables/SO/objects and caches. Build/log end-of-line spaces are preserved in scoped whitespace attributes. No new algorithm or performance improvement is claimed.
