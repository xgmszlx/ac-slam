# Reproduction of NGD-M0-compat-v2

Parent publication40035951ba461fc782fc47db5b61d4675c80e6f0; author a93a14c4019efc7a209be5fbf9fefa46f5d1d90f. Existing private OpenCV4.5.5, Pangolin, models and TUM walking inputs are reused. Paths in scripts reflect this workstation.

1. `python3 code/build_v2.py`: one-time refusal to overwrite; records old hashes, copies428 accepted author files from v1, changes only Tracking's CCL selection, retains YOLO's prior SAUF expression, freezes build commands, compiles Tracking only, reuses YOLO-v1 and all other original objects and links the original headless entry object. No algorithms or system libraries modified.
2. Compile `code/ccl_tracking_probe.cc` with `/usr/bin/g++ -std=c++14 -O2 -g`, the private OpenCV include/lib/RPATH, `-lopencv_imgproc -lopencv_core`, output external `.../ngd_ccl_compat_v2_20261020/ccl_probe`. `python3 code/test_ccl.py` launches24 bounded independent processes. Foreground labels are canonicalized against BFS. Maximum region and 7x7 dilation preserve Tracking's semantics including the author's empty-foreground fallback. Large label arrays remain external. This fixture is not an execution of the complete cluster/depth pipeline.
3. `python3 code/run_stage.py short`:12 continuous original inputs, exact original no-viewer entry, native TrackRGBD and export. This directory refuses overwrites. `... full` requires exit0 and12 completed calls; it launches exactly one complete827-input trial. Each stage freezes code/input hashes before start and captures command, resource use, actual loaded libraries, raw native messages and camera/KF files. The time wrapper exit0, completed frame markers and successful export together establish full execution; no online pose/state instrumentation is added.
4. `python3 code/evaluate.py <original walking directory> results/full evaluation`: unchanged previous evaluator, single rigid SE3 transform, scale1, unique20ms GT matching, 1s RPE +/-20ms and no intervening >100ms output gap. Its inherited plot fallback title says synthetic test when no legacy run.json is present; this misleading auto-figure is excluded from publication. Numeric outputs are unchanged. `python3 code/check_evaluation_and_plot.py` independently validates error math on the frozen matches and creates the correctly labeled published figure from this real run.
5. `python3 code/summarize.py` checks old-file/Git protection, contiguous completed calls and trajectory identity; it writes results/summary.json and a historical descriptive comparison. It does not run SLAM. Standard output/resources and results for short/full are never overwritten.

The archive omits raw data/GT, model weights/vocabulary, executables/SOs/objects and original binary label arrays. Old author and v1 sources/binaries remain at their original external paths. Two four-connected SAUF selections are compatibility changes. Empty pointsDepth, the 80% rule, roll expression and native asynchronous shutdown are deliberately unchanged. No online trajectory/state trace is available and no statistical performance claim is made.
