# P1 · A/B/C 三组特征层对照（2026-10-23）

## 0. 判决

`MECHANISM_CONFIRMED_AT_FEATURE_LEVEL` + **`B > C > A`**（特征数量与空间分布两项）。
但**几何质量未测**，且共同帧只有 6 个、单一序列，不足以定案。**不宣称方法收益。**

## 1. 三组的实现（同二进制，环境变量切换）

| 组 | 开关 | 行为 |
|---|---|---|
| **A 原生** | 无 | `nFeatures*1.5` 提取，八叉树在**整幅图**分配预算，事后按 mask 删除 |
| **B 预剔除** | `NGD_ORB_PRECULL=1` | 掩码按各层金字塔尺寸缩放，FAST 候选**进入 OctTree 之前**逐点过滤 |
| **C 补提取** | `NGD_ORB_REPLENISH=1` | 先走 A 的路径（含删除），再在 **mask==0 区域**做一次受限 FAST，按响应补到目标预算 |

三组共用同一二进制、同一输入、同一掩码来源。C 的目标预算由
`NGD_ORB_REPLENISH_TARGET=1500`（= `nFeatures*1.5`）给定。

**C 的实现说明（必须一起引用）**：补提取点的描述子来自 `cv::ORB::compute`
（patch 31、WTA_K 2、单层、Harris），**不是** `ORBextractor` 内部的
`computeOrbDescriptor`。两者可比但不逐位相同，因此 C 是**基线充分性探针**，
不是逐位重建。

## 2. 单测 7/7 通过（`tests/test_precull.cc`）

覆盖：空 mask 开关等价、满 mask 归零、半幅 mask 内部为零、原生路径确实忽略 mask、
预剔除后预算仍能填满、左右对称、掩码尺寸不匹配不崩。

### 单测抓到的两个真实缺陷
1. `static const bool` 缓存了首次调用的环境变量 → 同进程内开关失效（A/B 正式运行不会暴露）。
2. 关键点坐标相对 `minBorderX/Y`，索引掩码时未补偏移 → **边界漏点**，
   且**左右不对称**（左半正常、右半漏 93 个）。

## 3. 结果（按帧时间戳配对，三组共同帧 6 个）

| 组 | 特征中位 | vs A | 网格覆盖 | 最近邻距离中位 | 特征/格 |
|---|---:|---:|---:|---:|---:|
| A | 1139 | — | 0.927 | 1.12 | 25.8 |
| **B** | **1501** | **+30.87%** | **0.941** | 1.11 | 33.2 |
| C | 1419 | +23.52% | 0.927 | 1.74 | 31.8 |

逐帧（A / B / C）：
```
1106 / 1502 / 1383
1105 / 1496 / 1399
1043 / 1499 / 1383
1172 / 1501 / 1440
1204 / 1502 / 1450
1250 / 1504 / 1443
```

### 解读
- **B 稳定打满 1500 预算**（1496–1504），A 只用到 76%（1043–1250）→ 假设的预算浪费被实测到。
- **C 补回了大部分**（+23.5%），但仍比 B 低 **5.6%**，且逐一帧都低于 B。
- **空间分布上 B 也更好**：覆盖率 0.941 > 0.927，最近邻距离与 A 持平（1.11 vs 1.12）
  说明 B 多的特征**不是堆在同一处**；C 的覆盖率没有提升（0.927），最近邻距离反而变大（1.74），
  说明补的点更散但没填上新区域。
- 因此**"简单补提取已经足够"这一条目前不成立**——C 接近但不等效。

## 4. 不能主张的（必须同时引用）

1. **特征更多 ≠ 几何约束更好**。未测：静态几何一致匹配数、匹配正确率、PnP 内点/成功率、
   位姿误差、有效三角化比例。这是下一道门，也是唯一能定案的证据。
2. 共同帧只有 **6 个**、单一序列（fr3_sitting_xyz 前 120 帧）、无跨序列重复。
3. 位姿噪声底 0.404 cm 中位 / 3.263 cm 最大；特征数也受关键帧选择影响，
   因此配对比较只消除"帧不同"这一项混淆，不消除运行波动。
4. C 的描述子来自 OpenCV `cv::ORB`，与 A/B 不完全同源。

## 5. 下一步（判据顺序）

1. **几何层指标**：三组同帧下比较静态一致匹配数、PnP 成功率与内点、位姿误差。
2. 若几何无改善 → `SIMPLE_BASELINE_SUFFICIENT`（B 只是把预算填满，没有带来更好的几何）。
3. 若 B 有稳定几何优势且 C 不能达到 → 才有资格谈机制。
4. 跨序列重复（walking_halfsphere / walking_xyz）+ 多运行，对照噪声底。
