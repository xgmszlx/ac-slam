# P1 · 最终判决（2026-10-23）

## 0. `NO_POSE_BENEFIT_DETECTED` —— 机制为真，收益为假

**预算浪费的机制被实测确认**（B 比 A 多 30.9% 特征、28.1% 有效 3D、21.0% 几何分布广度），
**但这些都没有传导到位姿**。两条序列、每组 3 次重复，差异全部 ≤ 2 mm，
低于本系统 4 mm 级的跨运行噪声底。

## 3. 为什么这个"负结果"是有价值的

1. **它把假设从"听起来合理"变成了"已测否"**：预算浪费真实存在（A 只用 76% 预算），
   修掉它确实多出 30% 特征与 28% 有效 3D 约束——**但位姿没有变好**。
2. 这直接说明：**在本系统、本场景下，静态区的特征预算不是位姿精度的瓶颈。**
   瓶颈在别处（深度质量、匹配策略、后端优化、或动态点的其他影响途径）。
3. 它同时给出 `C ≈ B`（甚至略好）的证据：**简单补提取已经足够**，
   不需要为此开发新的特征分配机制。
4. 因此 P1 不再适合作为方法主线。若将来重启，需要新的证据说明"特征预算"
   确实是某个具体失效的瓶颈，而不是继续优化分配策略。

## 4. 必须保留的不确定性

- 每组 3 次重复只能估计组内波动，**不能**排除更细的效应；
  但观察到的组间差异（0.2–1.0 mm）**小于**组内波动（0.6–2.5 mm），
  所以在现有精度下**不可分辨**。
- 只测了 `*_xyz` 两条序列的前 120 帧，不是完整序列。
- B 在 walking 上组内跨度最小（0.8 mm），是**弱信号**：可能更稳定。
  不构成主张，需要更多重复才能判断。
- C 的描述子来自 `cv::ORB`，与 A/B 不同源，这使 C 的比较略有保留。
