## 3. 第一候选V3：跨表面的位置误差，是否应由一个高方差观测来代表？

**具体问题**：静态室内场景中，一个图像关键点附近有近/远两个深度表面。图像位置存在小误差时，所对应的depth可能属于另一个表面。我们要检验：把该观测保留为单个depth＋协方差，或整体弃掉depth，是否都会损失位姿估计所需的信息？

**原始依据与边界**：[MAC-VO §III-C](https://arxiv.org/html/2409.09479v2)直接讨论该耦合问题；[固定源码](https://github.com/MAC-VO/MAC-VO/blob/8683b532d6f6e8981f6b1a646fb5f52f02c1ea61/Module/Covariance/Project2to3.py)验证其输出形式。现有ORB3的RGB-D关键点读取单个depth，详见[SOURCE_AUDIT](audit/SOURCE_AUDIT.md)。这些证明表示选择和原始问题有依据，**没有证明MAC-VO在此必然失败，也没有证明现有ORB3的某次错误来自该机制**。协方差模块中局部均值用于协方差传播，不能据此断言配准点坐标被换成混合均值。

**借鉴机制**：COMO的跨视点可见性/深度兼容检查。目的不是训练一个新检测器，而是检验能否在同一表面上绑定图像对应与depth。已有概率RGB-D深度融合也必须作为近邻，见矩阵的经典冲突提醒。

| 项目 | 直接组合 | 候选针对性改进，尚未实现 |
|---|---|---|
| 表示 | MAC式完整协方差＋COMO式可见性门；冲突观测降权或拒绝 | 在小的位置不确定范围内保留少量表面depth分支，按两视图可见性和共同几何选择/边际化；不在一个高斯统计内提前消除表面身份 |
| 对应机制 | 一套对应配一个协方差；检查是否兼容 | 表面归属与位姿残差共同约束，模糊归属时可退回2D约束，不强行选近面/远面 |
| 可能独立差异 | 组合本身不新 | 只可能来自**何时保留表面歧义、如何保持源/目标同一表面、何时退回2D而不损失约束**的统一有限计算机制 |
| 必须排除的情况 | 简单门控已足够 | 若门控/完整协方差/成熟深度融合已足够，复杂分支无必要，立即停止 |

**这不是已确定的新算法**。混合似然、max-mixture、概率深度融合均是成熟概念；仅在ORB3换成RGB-D、换一个分布名或加权不能成为贡献。尤其RAS2018已有时空混合深度融合，其完整优化机制本轮未认证，因此NOVELTY_SPACE仍**UNRESOLVED**。现阶段不承诺该候选能发表。

最强的反对解释还包括：MAC-VO前端已经利用全局上下文选对表面，后端单高斯足够；或ORB3已有匹配/鲁棒核已拒绝问题观测。**输出单高斯并不等于必有多峰剩余误差**，不能仅凭接口形状制造“原作者不足”。

可实现的输入为现有RGB、注册depth、标定、关键点位置/尺度、在线匹配及估计位姿；局部depth分支和可见性均不得用GT选取。输出必须是改进的真实相机位姿/覆盖，不是一个“更合理”的质量分数。最小阶段不需要学习网络、外部语义或新的SLAM后端。任何位置不确定性估计仍需验证，不能把ORB尺度或点集形状直接当已校准协方差。

**最接近竞争方法**：MAC-VO完整协方差与现有GaussianMixtureCovariance、COMO可见性裁剪、概率时空深度融合；简单基线为depth边界无效化、保留RGB观测。未来正式方法比较必须包含这些合理机制，不能只击败原ORB3。

**最小反证**：先在一条静态、真实GT的小RGB-D序列中，原生ORB3与简单depth无效化各3次，全部保留。若简单处理已可靠改善轨迹、覆盖与成本，停止复杂模式研究；若原生本来健康，也停止该场景。二者都差并不能直接证明模式丢失，需要与运动、薄结构匹配、depth稀疏等竞争解释区分。

工程估计：数据门合格后的原生/简单输入处理为约1–2工作日；完整模式似然与索引、数值、基线认证为数周量级，属于推测，**本轮不启动**。部署MAC-VO全链需要额外模型/环境空间，若以后无法提供，则不能声称完成该作者系统上的改进验证。

## 4. 第二候选V2：局部照明变化，如何避免亮度补偿吸收真实运动？

**锚定COMO**：其全文§3.3采用每帧全局仿射亮度，并在结论提出更鲁棒对应为后续方向。限定场景为静态房间中局部光源/室内灯切换，同时相机正常运动。全局亮度不能表达任意局部照明，是模型表达范围的事实；**该限制是否造成无法被成熟方法解决的轨迹损失仍未知**。

**可借鉴I²-SLAM**：把曝光/外观作为估计变量，不依靠先增强图像。直接组合是把成像变量纳入COMO；候选差异是利用注册depth限制可用于解释亮度变化的空间区域，将照明自由度与运动约束分开，避免自由局部补偿解释掉几何误差。输入为RGB-D、局部对应和已有位姿预测；输出为相机pose与受限照明参数。可观性、约束选择和参数数量须有数学论证，不能仅加可靠性权重。

**关键反对证据**：AirSLAM引用的[Kim等，Autonomous Robots2019，作者稿摘要](https://mpil-gist.github.io/assets/paper/2019_auro_autonomous.pdf)已经使用patch级仿射照明模型和特征VO运动先验。因此“局部亮度补偿＋几何/运动先验”这个宽机制有**NOVELTY_CONFLICT**。仅换成depth先验并不自动构成独立差异。是否有更窄、非等价的耦合问题，本轮**UNRESOLVED**，不通过增加模块挽救。

最强简单基线包括原生ORB3、固定CLAHE、全局仿射光度对齐和已有局部仿射对齐；强系统近邻为AirSLAM和I²-SLAM。若普通局部仿射方法已足够，无新增机制必要。

最小反证只能是未来在ETH3D灯光训练序列上的完整轨迹比较，不用伽马变换制造真实光照证据；比较误差、覆盖、完整耗时而非亮度/特征数。它需要额外直接对齐模块或新密集系统，当前未部署。估计数周，资源和公平基线成本高于V3。**本轮不推荐开展该实验，更不启动COMO/I²平台建设。**

## 5. 四件事分开判断

| 判断层 | V3深度表面归属 | V2照明/运动分离 |
|---|---|---|
| 问题真实存在 | 文献支持：位置误差和depth边界耦合 | 文献支持：真实光照变化使定位变难 |
| 锚定方法存在范围限制 | 事实：每点协方差表示；不是已证失败 | 事实：全局仿射模型；不是已证具体失败 |
| 合理已有方法仍不足 | **UNKNOWN**，先做简单反证 | **UNKNOWN**，局部模型/强特征已存在 |
| 我们有未覆盖算法空间 | **候选，UNRESOLVED**；不能只做GMM | 宽机制**CONFLICT**；窄差异UNRESOLVED |
| 当前平台 | 原生ORB3已合格；新数据尚待验收 | 作者全链未合格，需要更多依赖/改造 |
| 是否小实验 | **建议一次受限问题验证，先过数据/磁盘门** | **暂不建议** |
| 是否SCI方法开发 | **不建议，缺真实剩余损失与充分排重** | **不建议** |

第一优先选择V3是因为其表示差异可检查、简单否定实验成本低；不是因为它已比V2更有论文创新，也不是为了复用walking负结果。V4本轮不进入最终两个候选：参考地图、跨时段数据和重定位评价会新增工程，而尚无更明确的剩余能力要求。

## 6. 下一轮唯一任务及停止条件

**只建议“ETH3D cables_3的一次原生/简单depth处理必要性试验”**，详见[具体协议](protocol/NEXT_MINIMAL_TEST.md)。输入313帧完整RGB-D、真实GT仅离线；B0/B1各最多3次，SE3-ATE、1s-RPE、覆盖/最长缺口、map身份、全部预处理/运行成本共同判断。不开发表面模式算法，不同时启动灯光实验。

原生系统与已有评价可复用，但新数据不因此自动合格。[空间审查](audit/DATA_FEASIBILITY.md)记录：本轮约1.90GB可用，保留1GiB后只余约0.77GiB新增峰值预算；数据服务器HEAD超时，压缩与解压字节数仍UNKNOWN。下一次只有先核对官方zip中央目录/容量、标定和GT，才能启动。超预算或无法验收即停止；不删除旧资料、不以减少安全余量强行开跑。

科学停止：无原生任务损失；简单处理已足够；改善只靠少输出；效果在重复波动内；不能区分初始化/运动/深度/匹配解释；成熟概率融合已等价覆盖。工程停止：单序列和既有程序仍需大量平台改造；时间/坐标身份不能认证；内存/空间门不过。工程停止不作为科学负结论。

最可能的SCI审稿攻击是：“这是2018概率RGB-D的再实现”“只是把MAC-VO统计搬到ORB3”“只改善一个短序列”“缺少强系统与等输入比较”“用表面残差代理真实轨迹”“用GT选择模式”。当前尚不能排除这些攻击。一次低成本反证有价值；**不能据本轮文献/源码审查就宣布方法必要或论文立项成功。**
