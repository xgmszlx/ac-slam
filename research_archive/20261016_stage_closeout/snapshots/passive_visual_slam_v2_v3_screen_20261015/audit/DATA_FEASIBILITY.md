# 小数据与空间资格

没有下载图像、depth、GT、模型或压缩数据；只有网页文本及HEAD请求。

## 可用公开入口

[ETH3D数据页](https://www.eth3d.net/slam_datasets)列出训练集`cables_3` 313帧、`cables_2` 98帧和`einstein_global_light_changes_2` 471帧；分别有mono与rgbd文件。不要假定rgbd包含RGB，应核对两包目录。cables场景是桌面线缆，官方提示可靠RGB特征困难；并非我们已经证明它有错误深度。灯光序列由开关室内灯形成实际变化，不需要人为调暗。

[官方格式](https://eth3d.ethz.ch/slam_documentation)：训练序列提供GT；彩色图经去畸变，RGB-D同视点、尺寸、同步，depth为16位/5000，无效0；深度来自主动红外双目。不能把它误称为与彩色stereo对应匹配计算出的深度。具体序列标定、GT有效段仍需本地验收。全暗序列官方明确RGB没有信息，不用它制造纯视觉失败。

[官方概览](https://www.eth3d.net/slam_overview)：大部分训练/测试使用动捕，另有五条sfm训练序列。拟议cables/灯光不属于sfm前缀，未来仍须验收下载文件，不能只凭命名完成坐标资格。

| einstein_global_light_changes_2，471帧，V2备选 | 真实开关灯，有公开标定/GT规范 | 包大小、屏幕等局部动态干扰、光照与RGB轨迹具体表现；不将其当纯光照因果对照 |

两个ETH3D官方host的页面本机SSL失败；两项灯光mono/rgbd HEAD超时，见data_head_only.json。浏览器检索缓存能取得官方目录/规范，不等于本机已下载可用。没有绕过失败继续抓数据。

## 必须先算空间，不能用帧数代替

本轮开始free=1,896,042,496字节。预留1GiB后，新增峰值可用822,300,672字节；运行前重新读取free，不能沿用这个旧值。

下一轮仅可先获取官方zip的长度及中央目录元数据。需要同时满足：

`mono压缩 + rgbd压缩 + 两包去重后解压文件 + 临时文件 + 结果上限50MiB + 1GiB安全余量 <= 当前free`。

仅有Content-Length还不足以计算解压大小。若Range/中央目录不支持、服务器不可达或总量超限，**停止数据验收，不删旧数据、不扩大磁盘工程、不直接下载碰运气**。没有已确认的容量数字，不能写成磁盘已合格。此时是DATA/RESOURCE_INCOMPLETE，不是科学反证。

许可、原始文件校验信息、完整RGB-depth对应和GT坐标需随数据一起验收；不能仅凭文件名通过。若作者无hash，记录HTTPS官方来源和本地hash，诚实区分来源认证与作者checksum。
