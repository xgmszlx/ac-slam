# 统计单位强制规范（跨方向，2026-10-23）

起因：L1 把 6541 / 4324 条连续记录当作独立帧做确认性判决，而滞后自相关达 0.974–0.995。
同一错误的变体在本仓已出现多次（Bonn GT 坐标系混用、n=1 ATE 故事、把 `σ_eff` 当中位 NEES 的换写）。

## 0. 强制要求

**每条方向在报任何主指标之前，必须先写明"科学独立单位"是什么，以及该指标的不确定性怎么估计。**
未写者，其结果只能登记为 `DESCRIPTIVE`，不得用于判决。

## 1. 先定独立单位，再定估计方法

审查提出的顺序是对的，采纳为强制顺序：

1. 科学独立单位是什么？（独立场景 / 独立序列 / 独立运行 / 独立任务 / 独立视角）
2. 该指标的抽样不确定性由什么决定？
3. 选与 1–2 相称的不确定性估计方法。

**禁止两种做法**：
- 把逐帧（相关）样本当独立试验凑显著性；
- 反过来机械统一套 AR(1) 公式。

## 2. 按统计量分列（不得混用同一个 n_eff）

| 统计量 | 独立单位 | 不确定性来源 |
|---|---|---|
| ATE / RPE 均值 | 独立运行或独立序列 | 运行间波动；序列内帧只作描述 |
| 相关系数（如 Spearman） | 独立运行/序列 | 相关系数自身的抽样分布，且序列内自相关 |
| P99 等尾部量 | 独立**极值事件** | 极端误差是否集中在少数连续事件；连续帧的 P99 不是独立分位数 |
| 成功率（主动 SLAM） | 独立任务运行 | 任务级成败，不是帧级 |
| 特征匹配正确率 | 独立镜头/场景 | 一万个匹配点 ≠ 一万个独立场景 |
| 稠密地图完整性 | 独立重建 | 百万地图点 ≠ 百万次重建 |

## 3. 本仓已发生的实例（作为反面教材）

| 实例 | 独立单位被误用为 | 后果 |
|---|---|---|
| L1 G1（本轮） | 6541 连续帧 | 判决门 `n≥200` 实际只有 15.8–32.0，判决撤回 |
| P5 四次 desk 运行 | 4 次运行中的相邻帧 | 改善与异步自然变异不可分，只能 `INCONCLUSIVE` |
| R4 旧排名 | n=1 的 Δyaw | 被 21 行台账交叉表推翻 |

## 4. 报告格式

每个主指标至少附：
- `independent_unit`: 单位类型 + 数量
- `n_records`: 原始记录数（不与上者混同）
- `uncertainty_method`: 实际用的方法
- 若 `independent_unit` 数量 < 判决门要求 → 结果标 `INCONCLUSIVE`，不得出确认性判决

## 5. 与其他控制文件的关系

本规范是 `RESOURCE_LOCKS.md`（资源隔离）的统计对应物：
资源隔离防止实验相互污染，本规范防止**统计结论**相互污染。
违反本规范不产生运行失败，只产生**不可用的判决**，因此更危险。
