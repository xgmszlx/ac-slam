### 0.1 最重要的一条：**一个容易得出错误结论的坑，已被本轮自己的数据推翻**

如果只看"绝对位姿 NEES"，会得到"hector 的信息矩阵**过度自信 20–65 倍**"。
这个结论**是错的**，而且错在**我的口径**，不在系统：

| 口径 | NEES 中位 | 相对一致值 2.366 | 读法 |
|---|---|---|---|
| **绝对**（冻结一次性 SE(2) 对齐后的位姿误差） | 150.3 / 44.6 | **63.5× / 18.9×** | 看起来"严重过度自信" |
| **相对**（逐帧增量，= 冻结 ICP 归档的原口径） | 1.54 / 1.01 | **0.65× / 0.43×** | 实际**略偏保守，量级正确** |

差别的原因是**漂移**：偏航误差的一阶自相关为 **0.977 / 0.974**，
按四个时间四分位其绝对值中位为 **17.8 / 17.1 / 28.3 / 20.5 mrad**——**不随时间增长，是一个近似常值的偏置**。
逐帧 Hessian 描述的是"本帧匹配精度"，**按构造不可能**预测无回环系统的累计偏置。
把两者相除得到的 63×，是**口径伪影**，不是系统缺陷。

## 2. G0：谁是合格的原生信息矩阵源

`QUALIFIED_NATIVE_INFO_SOURCE = hector_mapping`。

`/hector_debug_info`（`hector_mapping/HectorDebugInfo`）每条消息带 `iterData[]`，
每项含 `float64[9] hessian`。实测 `iterData` 长度恒为 **11**，取**最后一次 LM 迭代**为收敛 Hessian。

被排除的（逐条有据，不是猜）：

| 候选 | 排除依据 |
|---|---|
| 2DLIW-SLAM | 无条件订阅 `sensor_msgs/Imu`；LILocBench bag **无 IMU**（`rosbag info` 实测） |
| `laser_scan_matcher` | 二进制里只有 `position_covariance`/`orientation_covariance` **两个参数名**——发布的是 launch 常数，不是逐帧计算 |
| AMCL | 粒子云后验协方差，口径不同（非扫描匹配 Hessian） |
| slam_toolbox / cartographer | 本机未安装 |

**附带发现（可独立复算的负结果）**：`hector_mapping` 发布的 `/poseupdate.covariance`
**不能当协方差用**——实测 `sd_x` 中位 **6.85 m**、`sd_θ` 中位 **569 rad**，
而同一时段机器人总位移仅 12.96 m 且跟踪正常。该矩阵对称半正定（`max|C−Cᵀ| = 0`），
所以是**尺度未文档化的内部量**，不是填错槽位。

## 4. 事后诊断：主结果为什么不能用（**口径伪影**）

### 4.1 偏航误差是漂移，不是逐帧噪声

| 量 | static_0 | lt_changes_0 |
|---|---:|---:|
| `e_θ` 一阶自相关 | **0.977** | **0.974** |
| `|e_θ|` 四分位中位 (mrad) | 17.75 / 17.05 / 28.28 / 20.54 | 14.69 / 16.13 / 17.56 / 11.29 |
| `σ_θ` 预测中位 (mrad) | 2.48 / 1.91 / 2.65 / 2.44 | 2.52 / 2.35 / 2.82 / 2.61 |
| 绝对口径 `z_θ` 中位 | 10.286 | 5.519 |
| **相对口径 `z_θ` 中位** | **1.026** | **0.807** |
| 逐帧增量 `|Δe_θ|` vs `σ_pred` | 3.443 vs 3.416 mrad | 3.259 vs 3.545 mrad |

一致模型的 `median|z|` 应为 **0.674**。相对口径下 `z_θ = 1.03 / 0.81` → **逐帧偏航精度估得基本正确（略保守）**；
误差近似常值且自相关 0.98 → 是**累计偏置**，逐帧 Hessian 结构上无法预测。

### 4.2 分轴分解（绝对口径）

| 轴 | `median|z|` static | `median|z|` lt | 一致值 | 解读 |
|---|---:|---:|---:|---|
| x | 0.220 | 0.370 | 0.674 | σ_x **偏大 1.8–3×**（保守） |
| y | 0.960 | 0.451 | 0.674 | 基本一致 / 偏保守 |
| θ | **10.286** | **5.519** | 0.674 | **唯一失衡的轴**（且已证为漂移） |

`Σ_xy` 的 `eig ratio` 中位仅 **2.2 / 2.3**（65.8% / 63.9% 的帧 < 3）→ **平移块接近各向同性**，
此前"各向异性 45×"的说法**不成立**，已撤回。（该数字来自含 θ 的 3×3 分解，被 θ 方向主导。）

### 4.3 单一全局尺度救不回来

| 量 | static_0 | lt_changes_0 |
|---|---:|---:|
| 使中位 NEES 达标的全局尺度 | 8.02 | 4.48 |
| 缩放后 σ_xy 中位 | **1.487 m** | 0.845 m |
| 实际误差中位 | 0.116 m | 0.084 m |
| 缩放后 σ 比误差大 | **12.9×** | 10.1× |

→ **不存在**一个全局尺度能同时让"联合 NEES"和"平移 σ"都合理。
差额全部由 θ 轴承担（即 §4.1 的漂移）。

## 5. 事后诊断：**有效的相对口径下，答案是什么**

标注 **`POST_HOC_DIAGNOSTIC`**，非预注册。**披露**：在写这一步之前，我已看到 θ 单轴的相对 `z`
（§4.1）；完整三轴相对结果此前未见。因此本节的结论**不能**当作确认性证据，
只能作为"下一轮该预注册什么"的依据。

| 量 | static_0 | lt_changes_0 | 预注册门 |
|---|---:|---:|---|
| `NEES_rel` 中位 | **1.536**（0.65×） | **1.010**（0.43×） | 一致值 2.366 |
| 尾重比 `R` | **8.275** | **12.234** | ① ≥ 5 → **双双通过** |
| Spearman(σ, err) | **+0.086** | **+0.063** | ②(a) ≥ 0.3 → **双双失败** |
| 五分位误差比 | **1.142** | **1.115** | ②(b) ≥ 2 → **双双失败** |

**读法**：
1. **量级是对的**（相对 NEES 中位 0.43–0.65×一致值，略保守），
   → 之前"3 倍 / 8–9 倍过度自信"的旧论断在本系统上**再次不成立**，与归档的撤回一致。
2. **尾部确实重**：P99 归一化 NEES 是一致 3 维高斯预期的 **8–12 倍**。失败在尾部，不在主体。
3. **完全没有预警能力**：秩相关 ≈ 0，且"预测 σ 最高五分位"的帧其实际误差反而只有最低五分位的
   **1.14 / 1.12 倍**。→ 直接把 Hessian 当在线可靠性/降级信号，**本数据不支持**。

## 6. 这个结果意味着什么 / 不意味着什么

**成立（有本机证据）**
- 一个真实、被广泛使用的 2D SLAM 包，其逐帧 Hessian 在**主体上量级正确、尾部重 8–12 倍**；
- 它**不能**预测自己的逐帧误差量级（两条序列一致，且与帧纳入规则、与口径选择都无关的只有这一条最稳）；
- 它的 `/poseupdate.covariance` 字段**不可直接用于 NEES**；
- 冻结门本身有**未枚举区间**，且其"绝对 NEES"表述对**有漂移的系统**会给出误导性结论。

**不成立（必须守住）**
- **不能**说"2D 激光 SLAM 过度自信"——本系统在相对口径下略**保守**。
- **不能**说"高斯协方差无法描述扫描匹配误差"——只能说**尾部**不符（P99 8–12×）。
- **不能**外推到来 hector 之外的系统（只测了 1 个系统、2 条序列、1 个平台）。
- **不能**声称任何方法贡献。本轮是机制测量。

## 7. 若结果为零/反向，意味着什么

本轮结果**部分反向**（否掉了"过度自信"、"能预警"两条），这恰好是最省钱的结局：

- "不能预警" ⇒ **`HOLD`**，不做基于 Hessian 的在线可靠性/降级状态机；
  该机制若要复活，必须先证明"秩相关缺失是口径造成"——§5 已在有效口径下排除。
- "尾部重 8–12×" ⇒ 留下**唯一**可立项的问题：
  一个**二阶矩正确、P99 差 8–12 倍**的协方差，能否用**分布层面**（而非尺度层面）的修正改善？
  但它的直接近邻是 SR-SLAM 的可靠性、CC-DPMS 的风险策略——**新颖性 `UNRESOLVED`**，
  在排重完成之前**不得**写方法动机。
