## 1. 🚧 先说一个刚查出来的硬阻塞

**2DLIW-SLAM 在 LILocBench 上跑不起来。**

| 检查项 | 证据 |
|---|---|
| 2DLIW 必需输入 | `src/lvio_2d_node.cpp:12` 无条件订阅 `sensor_msgs/Imu`；系统坐标系原点就是 IMU（作者 README 明说） |
| LILocBench `static_0.bag` 实际 topic | `cmd_vel`、`odom`、`joint_states`、`laser_scan_front/scan`、`laser_scan_rear/scan`、`/tf`、`/tf_static` —— **没有任何 IMU** |
| 2DLIW 外参 | `config/*.yaml` 里的 `T_imu_to_laser` / `T_imu_to_wheel` 是**作者平台**标定值，直接套到 LILocBench（Dingo 底盘）物理上错误 |
| `code/not_executed/merge_imu.py` | 曾尝试把 `accel`/`gyro` 合成 `/d400/imu0`，但它是把**相邻两条不同种类消息**拼成一条 IMU（时间不对齐），且那几个 topic 也不在 LILocBench 的 bag 里 |

**结论：不能用合成 IMU、不能用作者外参、不能把 4 小时耗在一个注定跑不通的组合上。**

## 3. G1 科学门（数字事先写死）

**输入**：`static_0` + `lt_changes_0`（或 G0 选定的替代序列），**全分辨率、不降采样**。
**导出**：每帧 `Hp`（位置 3×3）、`Hq`（旋转 3×3）、该帧位姿、`n_lines`、时间戳；**只读累加，不改任何数学、不改优化、不改状态**。
**评价**：与 `code/audit_consistency.py` 完全同一口径（`NEES = eᵀ H e`，3 自由度），参考位姿来自 GT 的相对位姿。

**判据只用尺度无关量**（绝对 NEES 阈值一律不用，因为它依赖未知的真实测距噪声，见 `REPORT.md` §3.2）：

| 观测（≥200 帧） | 判定 | 后续 |
|---|---|---|
| 归一化尾部 `u(P99)/4.795 ≥ 5`，**或** `(x,θ)` 预测相关与实测符号相反，**或** rank 相关(NEES, 预测σ) 的绝对值 < 0.2 且尾部预测σ不比其余帧宽 | 🟢 复核成立：该协方差模型覆盖不了自身失败，可进入方法设计 | 允许写方法动机章节 |
| 上述三条中只命中一条，或量级明显较小 | 🟡 部分成立，先定标定问题（哪个是未知尺度） | 只做诊断，不写主张 |
| `u(P99)/4.795 < 1.5` 且三条皆不成立 | 🔴 本线观察属简化 ICP 伪影 | **立即关闭本线** |

**同时必须报告**：真实测距噪声的**独立标定**（静止数据估计或用数据手册），否则"过度自信"永远无法与"σ 假设错"分开。这是本线目前**唯一的结构性未知量**。

**尾部度量**：一律用 `γ_xy`（平移 2×2 块），**禁用**混合单位 `λmin/λmax`（见 `REPORT.md` §4.5）。

## 4. 禁止事项（防止重演前三轮的模式）

1. 不许在看到结果后调整 `σ_range` 档位、降采样率、`rmax`、Huber 阈值来"找到"过度自信。
2. 不许用某一条序列的结论外推到"2D 激光 SLAM"整体。
3. 不许把 `σ_eff` 当独立发现（它是中位 NEES 的换写，见 `REPORT.md` §4.4）。
4. 不许用**部分日志**算 NEES（前三轮已经有两次因 abort 丢缓冲的教训）。
5. 一次预算：每条序列 1 次，失败保留不重跑。

## 5. 备选（若 G0 判定"没有合格原生协方差源"）

用**同一套 IPC** 做两次可解释的口径升级，明确标注"仍是本仓实现"：

| 升级 | 解决的问题 | 成本 |
|---|---|---|
| scan-to-**submap**（滚动子图，最近 N 帧合成局部地图） | 报告局限 #1 | ~半天，复用 `scanmatch.py` |
| **全分辨率**（去掉 `[::4]`） | 报告局限 #2 | 一次重跑，时间约 4× |

这两条做完，只能支持"在本仓实现上、全分辨率、子图匹配下仍然过度自信"，**不能**支持任何真实系统主张。若 G0 有解，优先 G1。
